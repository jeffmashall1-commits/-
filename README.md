# README — Fix / Excel Cleanup

این شاخه (fix/excel-cleanup) شامل یک اسکریپت پایتون است که فایل اکسل اصلی را می‌خواند، شیت‌های خام را در شیت‌های Data_Raw_* قرار می‌دهد، پاک‌سازی پایه‌ای انجام می‌دهد و شیت‌های Data_Clean_* و یک شیت گزارش (Report_Print) می‌سازد.

چگونه استفاده کنید:

1. کلون کردن یا دانلود این شاخه (fix/excel-cleanup).
2. نصب پیش‌نیازها:
   pip install pandas openpyxl jdatetime numpy

3. قراردادن فایل اصلی اکسل در همان پوشهٔ اسکریپت (یا استفاده از مسیر full path). نام اصلی شما:
   ‎⁨سیستم ثبت برگه ورود خروج نهایی⁩.xlsx

4. اجرای اسکریپت:
   python cleanup_and_build_excel.py "‎⁨سیستم ثبت برگه ورود خروج نهایی⁩.xlsx" "سیستم ثبت برگه ورود خروج نهایی - fixed.xlsx"

5. بعد از اجرا یک فایل خروجی به نام 'سیستم ثبت برگه ورود خروج نهایی - fixed.xlsx' ساخته می‌شود که شیت‌های زیر را دارد:
   - Data_Raw_<original_sheet_name>
   - Data_Clean_<original_sheet_name>  (تاریخ‌ها به صورت رشتهٔ شمسی YYYY/MM/DD تبدیل شده‌اند)
   - Report_Print (خلاصه‌ای از شیت‌ها)
   - README (این توضیحات)

محدودیت‌ها و توضیحات:
- اسکریپت سعی می‌کند ستون‌های تاریخ را تشخیص دهد، اما بسته به ساختار دادهٔ واقعی ممکن است نیاز به تنظمیات دستی داشته باشید (نام ستون‌ها غیرمعمول، فرمت‌های متغیر، سل‌های ادغام‌شده در هدرها).
- داشبورد، اسلایسرها و پیوت‌ها در نسخهٔ اولیه ساخته نمی‌شوند؛ هدف این مرحله ارائهٔ یک فایل پاک‌سازی‌شده و ساختار یافته است. اگر مایل باشید بعد از این مرحله من می‌توانم یک فایل نمونهٔ داشبورد (با دادهٔ نمونه یا پس از بررسی دادهٔ تمیز) تولید کنم.
- لوگو در هدر/فوتر قرار نگرفت؛ فضای آن در Report_Print در نظر گرفته شده است (شما می‌توانید تصویر موردنظر را بعداً اضافه کنید).

اگر می‌خواهید من نسخهٔ نهایی اکسل را مستقیماً تولید و در این شاخه آپلود کنم (به جای اسکریپت)، باید فایل خام را به طور امن در محیطی که دسترسی اجرای اسکریپت دارم قرار دهید؛ در غیر این صورت بهترین روش اجرای اسکریپت در سیستم شماست تا دادهٔ واقعی حفظ شود.

در قدم بعدی چه می‌کنم:
- اگر می‌خواهید من همین حالا اسکریپت را اجرا کرده و فایل fixed.xlsx را تولید و آپلود کنم، باید فایل اکسل اصلی را در محلی قابل اجرا قرار دهم یا شما آن را اینجا آپلود کنید (به عنوان یک فایل قابل‌دسترس). در غیر این صورت، شما می‌توانید اسکریپت را اجرا کنید و خروجی را بررسی کنید و من برای تولید داشبورد و Report_Print صفحه‌بندی شده آماده‌ام.
